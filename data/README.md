# Data

Raw data is not stored in this repo.

**MoneyPuck (season stats)**
1. Go to https://moneypuck.com/data.htm
2. Under season-level data, download the **Skaters** CSV for each season from 2021-22 to 2025-26
3. Save them here as `skaters21-22.csv`, `skaters22-23.csv`, `skaters23-24.csv`, `skaters24-25.csv`, `skaters25-26.csv`

**NHL EDGE and player profiles**
Run `notebooks/08_edge_data.ipynb`. It downloads them into `edge_raw/` and `bio_raw/` here (about 10 minutes each the first time).

Data courtesy of MoneyPuck.com and the NHL.
